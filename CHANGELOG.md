# Changelog

All notable changes to this project will be documented in this file.

The format follows the principles of [Keep a Changelog](https://keepachangelog.com/).

## [0.1.0] - 2026-08-11

### Added

* Initial `bdskit.cbx` citation style.
* Initial `bdskit.bbx` bibliography style.
* Numeric citation format based on `numeric-comp`.
* Automatic sorting of multiple citations.
* Automatic compression of consecutive citation numbers.
* BDS-inspired bibliography formatting.
* Family-name-first author formatting.
* Bulgarian quotation marks for titles.
* Page formatting using `С.`.
* URL formatting using `URL:`.
* DOI formatting using `DOI:`.
* Initial support for bibliographic entries containing Cyrillic and Latin text.
* Initial project documentation.
* Initial usage example.

### Notes

* This is an initial development release.
* The style should be considered BDS-inspired rather than an official implementation of a Bulgarian State Standard.
* Bibliographic formatting is subject to further development and validation against specific BDS requirements.
